# 🔒 Secrets Management Guide

This document explains how to safely manage API keys and other secrets in the Touch Grass app without exposing them to GitHub.

## Files That Should NEVER Be Committed

These files are in `.gitignore` and must never be pushed to GitHub:

### Firebase Configuration
- `lib/firebase_options.dart` — Real Firebase credentials (auto-generated by `flutterfire configure`)
- `google-services.json` — Android Firebase config
- `GoogleService-Info.plist` — iOS Firebase config

### Android Build Secrets
- `android/key.properties` — Key store credentials
- `android/app/*.jks` — Java key store files
- `local.properties` — Local build settings

### Web Secrets
- `web/maps_config.js` — Google Maps API key for web (copy from `maps_config.js.template`)

### Environment & Secrets
- `.env` — Environment variables (copy from `.env.template` and fill in)
- `secrets.dart` — Any hardcoded secret Dart file
- `secrets.json` — Any JSON secrets file
- `.env.local` — Machine-specific env overrides

## Setup Instructions

### 1. Firebase Configuration (Already Auto-Handled)

Firebase credentials are handled automatically:

```bash
flutterfire configure --project=touchgrass-23a9a
```

This creates `lib/firebase_options.dart` locally (gitignored).
- **Do not commit this file**
- **Each developer runs `flutterfire configure` locally**
- A template is provided at `firebase_options_template.dart` for reference

### 2. Google Maps API Key (Android/iOS/Web)

**Local Setup:**

1. Copy `.env.template` to `.env`:
```bash
cp .env.template .env
```

2. Add your Google Maps API key to `.env`:
```
GOOGLE_MAPS_API_KEY=AIzaSy...your-key...
```

**Android Setup:**

Add your key to `android/local.properties` (this file is gitignored):

```properties
MAPS_API_KEY=your_google_maps_api_key_here
```

The app injects this value into the manifest via Gradle placeholder `${MAPS_API_KEY}`.

**iOS Setup:**

Add the key to `ios/Runner/AppDelegate.swift`:

```swift
import GoogleMaps

@UIApplicationMain
@objc class AppDelegate: FlutterAppDelegate {
  override func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
  ) -> Bool {
    GMSServices.provideAPIKey("YOUR_GOOGLE_MAPS_API_KEY")
    GeneratedPluginRegistrant.register(with: self)
    return super.application(application, didFinishLaunchingWithOptions: launchOptions)
  }
}
```

**Web Setup:**

The web build uses the same key from `android/local.properties`. Run the generator script from the project root:

```bash
dart run tool/generate_web_maps_config.dart
```

This reads `MAPS_API_KEY` from `android/local.properties` and writes `web/maps_config.js` (gitignored).

Alternatively, you can copy the template and fill it in manually:
```bash
cp web/maps_config.js.template web/maps_config.js
# then edit web/maps_config.js and set your API key
```

## Checklist Before Pushing to GitHub

- [ ] `.env` exists locally but is in `.gitignore` ✓
- [ ] `web/maps_config.js` exists locally but is in `.gitignore` ✓
- [ ] `lib/firebase_options.dart` is NOT committed (gitignored) ✓
- [ ] `google-services.json` is NOT committed (gitignored) ✓
- [ ] `android/key.properties` is NOT committed (gitignored) ✓
- [ ] No API keys appear in any committed Dart files

## What Others Need to Do After Cloning

Each developer who clones this repo must:

1. **Set up Firebase:**
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure --project=touchgrass-23a9a
   ```

2. **Set up environment variables:**
   ```bash
   cp .env.template .env
   # Edit .env and fill in your Google Maps API key
   ```

3. **Set up Google Maps for web:**
   ```bash
   dart run tool/generate_web_maps_config.dart
   ```
   This reads `MAPS_API_KEY` from `android/local.properties` and creates `web/maps_config.js`.

4. **Android Firebase config:**
   - Download `google-services.json` from Firebase Console → Project Settings → Android App
   - Place it in `android/app/google-services.json` (gitignored)

5. **Build and run:**
   ```bash
   flutter clean
   flutter pub get
   flutter run
   ```

## If You Accidentally Commit Secrets

If a secret was accidentally committed to GitHub before this setup:

1. **Regenerate all secrets** (Firebase API keys, Google Maps keys, etc.)
   - Firebase keys can be regenerated in Firebase Console
   - Google Maps keys can be disabled/recreated in Google Cloud Console

2. **Remove from git history** (if you have access):
   ```bash
   git rm --cached <secret-file>
   git commit -m "Remove accidentally committed secrets"
   ```

3. **Force push** (if not yet merged to main):
   ```bash
   git push origin --force-with-lease
   ```

4. **Alert your team** immediately

## Best Practices

✅ **DO:**
- Store secrets in environment variables or `.env` files (gitignored)
- Use `.env.template` to document what secrets are needed
- Generate new secrets after any accidental leaks
- Use Firebase Rules to limit access to data
- Rotate API keys periodically

❌ **DON'T:**
- Commit `.env`, `secrets.*`, or `firebase_options.dart`
- Hardcode API keys in Dart source files
- Share `.env` files via email or chat
- Keep the same API keys after a breach

## Staying Secure

1. **GitHub Secret Scanning** is enabled on this repo (detects leaked secrets)
2. **Branch Protection** requires reviews before merging
3. **Always review** what files are staged before committing:
   ```bash
   git status
   git diff --cached
   ```

For questions, contact the development team.
